# MiniTMS: Архитектурные решения и Конфигурация (Единый источник правды)

Этот документ фиксирует окончательные архитектурные и бизнес-решения по проекту MiniTMS, разрешая любые исторические противоречия в спецификациях.

## 1. Базовые единицы измерения
- **Вес:** строго **Килограммы (кг)** во всем приложении (БД, DTO, API, Фронтенд). Любые упоминания тонн в исторических спеках считаются устаревшими.

## 2. Инфраструктура и Хранение
- **База данных:** **PostgreSQL 15+**. Версии ниже 15 не поддерживаются.
- **Шина сообщений (Очереди):** **Celery + Redis**. RabbitMQ не используется.

## 3. Внешние Интеграции
- **GPS-провайдер:** **GPS Guard**. Интеграция с Wialon/Navixy отменена.
- **Telegram Бот:** **Отложен**. Функционал уведомлений в Telegram временно заморожен, токен TELEGRAM_BOT_TOKEN пока не используется.

## 4. Бизнес-логика (Пороги и Отклонения)
Необходимо строго разделять две разные метрики:
1. **Рентабельность груза (Profitability):** Считается на этапе скрапинга (ate_per_km). Цветовые пороги: RED, YELLOW, GREEN, GRAY.
2. **Отклонение План/Факт:** Считается в модуле отчетов после завершения рейса. Пороги: <10% (зеленый/норма), >10% (красный/превышение).
