# Отчёт о соответствии кода и документации MiniTMS (актуальный)

**Дата актуализации:** 20 сентября 2026
**Объект:** проект MiniTMS — документация `docs/` (44 документа) против реализованного кода backend/frontend в `/opt/minitms`.
**Репозиторий:** github.com/Mumuaki/minitms_a, ветка `main`.
**Метод:** последовательный аудит соответствия, пошаговое закрытие разрывов, проверка изменений через живое API и unit-тесты. Каждый шаг закоммичен и запушен в `origin/main`.

---

## 1. Резюме

В `/opt/minitms` развёрнут и работает полный стек MiniTMS (Docker Compose, 10 контейнеров): core-api, cargo-engine, scraping-worker, integration-hub, gateway (nginx), frontend (React/Vite), PostgreSQL, Redis, celery-worker/beat.

- **Unit-тесты:** 85 passed (`python -m pytest backend/tests/unit -q`).
- Аутентификация: JWT (HS256) + refresh-cookie (httpOnly), RBAC по ролям, rate-limit входа, audit-log.
- Все backend-модули имеют рабочие эндпоинты; все страницы фронтенда наполнены реальным функционалом.

**Оставшиеся разрывы** связаны только с внешней инфраструктурой/доступами (раздел 5) и не могут быть закрыты кодом без данных от владельца.

## 3. Закрытые разрывы (ключевые)

- 500 на `/cargos` из-за отсутствующих колонок — добавлена миграция `6f2b9d4e8a1c`.
- 400 на списке грузов — исправлен маппинг DTO (`_dto_to_response`).
- 405 при редактировании пользователя — добавлен `PUT /users/{id}`.
- 502 на `/scraping/*` — entrypoint скрапера запускает uvicorn перед celery.
- Cargo `create/update` (NotImplementedError) — делегировано в `upsert`.
- Секрет JWT перенесён из кода в переменную окружения `SECRET_KEY`; RBAC добавлен на все пишущие эндпоинты.
- Настройки переведены на хранение в БД (`app_settings`).
- Email: подстановка переменных в шаблоны (FR-EMAIL-002).
- GPS: история перемещений ТС (FR-GPS-004).
- Фронтенд: сохранение пользовательских фильтров грузов (FR-UI-005).
- Уведомления: Web-Push в браузере (FR-NOTIFY-001).
- Фронтенд: детали груза по клику на строку (FR-UI-003) и фильтр по стране (FR-UI-004).
- Email: постоянное хранение шаблонов в БД и редактирование (FR-EMAIL-003).
- Google Sheets: живая синхронизация по OAuth 2.0 (FR-GSHEET-005/006).
