# Процедура ручного поиска грузов на Trans.eu

Актуализировано по результатам пошаговой отладки процедуры с оператором (23.05.2026).

---

## Шаг 1: Открытие страницы поиска грузов

Открыть в браузере: `https://platform.trans.eu/exchange/offers`

---

## Шаг 2: Развернуть фильтры (ОБЯЗАТЕЛЬНО — до ввода любых данных)

1. Нажать белую кнопку в правом верхнем углу с надписью синим шрифтом **«РАЗВЕРНУТЬ ФИЛЬТРЫ»** (или **«EXPAND FILTERS»**).
2. Нажать кнопку **«БОЛЬШЕ ФИЛЬТРОВ»** (или **«MORE FILTERS»**) — для открытия полной панели фильтров, включая даты и характеристики груза.

> **Внимание!** Кнопки разворота фильтров нажимаются ДО ввода любых данных поиска.

---

## Шаг 3: Очистить фильтры

Нажать кнопку **«Очистить фильтры»** (или **«Clear filters»**) — удалить все старые значения полей.

---

## Шаг 4: Ввод пункта загрузки (Загрузка)

1. Зафиксировать курсор в поле **«Найти локализацию»** под надписью **«Загрузка»** — сделать клик.
2. В появившемся модальном окне ввести информацию о пункте загрузки в одном из форматов:
   - `{ISO-2 страны}, {Индекс}, {Начало названия населённого пункта}` — например: `IT, 00131, Ro`
   - `{ISO-2 страны}, {Индекс}` — например: `IT, 00131`
   - `{ISO-2 страны}` — например: `IT`

   > **Внимание!** Менять почтовый код и название страны запрещено.

3. В появившемся динамическом списке выбрать запись с **максимальным совпадением по символам** (наиболее полная запись: Страна + Индекс + Город + Регион). Кликнуть на выбранной записи для фиксации.

---

## Шаг 5: Проверить радиус загрузки

После фиксации пункта загрузки рядом с полем появляется дополнительное поле радиуса.

- Значение по умолчанию: **+ 75 km**
- Если значение отличается от + 75 km — скорректировать его.

> **Примечание:** Поле радиуса появляется только если выбрана точка вида «Страна + Индекс + Город». Если указана только страна или страна + индекс — поле радиуса может не появиться; искать его принудительно не нужно.

---

## Шаг 6: Ввод пункта разгрузки (Разгрузка)

По умолчанию поле **«Разгрузка»** оставляется **пустым**.

Если требуется задать пункт разгрузки — действия идентичны Шагу 4 (Загрузка):

1. Зафиксировать курсор в поле **«Найти локализацию»** под надписью **«Разгрузка»** — сделать клик.
2. Ввести информацию о пункте разгрузки в одном из форматов:
   - `{ISO-2 страны}, {Индекс}, {Начало названия населённого пункта}` — например: `DE, 80301, Munchen`
   - `{ISO-2 страны}, {Индекс}` — например: `DE, 80301`
   - `{ISO-2 страны}` — например: `DE`
3. В появившемся динамическом списке выбрать запись с максимальным совпадением по символам. Кликнуть для фиксации.
4. Проверить радиус разгрузки — значение по умолчанию: **+ 75 km**.

---

## Шаг 7: Проверить значение поля «Вес (т)»

Поле «Вес (т)» состоит из двух частей: левого поля «От» и правого поля «До».

- Правое поле **«До»** — значение по умолчанию: **0,9**
- Если значение отсутствует — ввести **0,9**.
- Если значение отличается от **0,9** — заменить на **0,9**.

---

## Шаг 8: Проверить значение поля «Длина (погрузочные метры)»

Поле «Длина (погрузочные метры)» состоит из двух частей: левого поля «С» и правого поля «До».

- Левое поле **«С»** — значение по умолчанию: **4,8**
- Если значение отсутствует — ввести **4,8**.
- Если значение отличается от **4,8** — заменить на **4,8**.

---

## Шаг 9: Установить даты загрузки (Дата загрузки)

Поле «Дата загрузки» состоит из двух частей: левого поля «ДД.ММ.ГГ» (С) и правого поля «ДД.ММ.ГГ» (По).

### Левое поле (С) — начало диапазона:
1. Зафиксировать курсор в **левом** поле «ДД.ММ.ГГ» под надписью «Дата загрузки» — сделать клик.
2. В появившемся модальном окне с календарём выбрать нужную дату (по умолчанию — текущая дата).
3. Кликнуть на выбранной дате для фиксации.

### Правое поле (По) — конец диапазона:
1. Зафиксировать курсор в **правом** поле «ДД.ММ.ГГ» под надписью «Дата загрузки» — сделать клик.
2. В появившемся модальном окне с календарём выбрать нужную дату (по умолчанию — та же дата, что и в левом поле).
3. Кликнуть на выбранной дате для фиксации.

> **Правило валидации:** Дата в левом поле «С» не может быть позже (больше) даты в правом поле «По».

---

## Шаг 10: Установить даты разгрузки (Дата разгрузки)

Поле «Дата разгрузки» состоит из двух частей: левого поля «ДД.ММ.ГГ» (С) и правого поля «ДД.ММ.ГГ» (По).

### Левое поле (С) — начало диапазона:
1. Зафиксировать курсор в **левом** поле «ДД.ММ.ГГ» под надписью «Дата разгрузки» — сделать клик.
2. В появившемся модальном окне с календарём выбрать нужную дату (по умолчанию — дата на 1 день позже правого поля «Дата загрузки»).
3. Кликнуть на выбранной дате для фиксации.

> **Допустимое значение:** левое поле «Дата разгрузки» при ручном вводе **может оставаться пустым**. Но только пустым — никакого иного значения кроме корректной даты быть не должно.

### Правое поле (По) — конец диапазона:
1. Зафиксировать курсор в **правом** поле «ДД.ММ.ГГ» под надписью «Дата разгрузки» — сделать клик.
2. В появившемся модальном окне с календарём выбрать нужную дату (по умолчанию — та же дата, что и в левом поле разгрузки).
3. Кликнуть на выбранной дате для фиксации.

> **Правила валидации (НАРУШЕНИЕ ЗАПРЕЩЕНО):**
> 1. Дата в левом поле «Дата разгрузки» (С) не может быть позже (больше) даты в правом поле «Дата разгрузки» (По).
> 2. Любое значение дат в полях «Дата разгрузки» (и левое, и правое) **не может быть раньше** (меньше) любого значения дат в полях «Дата загрузки».

---

## Шаг 11: Запустить поиск

После завершения ввода и проверки всех фильтров нажать **зелёную кнопку «Поиск»** (или **«Search»**) в правом верхнем углу экрана.

Дождаться завершения вывода данных на странице.
